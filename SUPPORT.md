# Support

## Questions and Usage Help

Use GitHub Discussions (preferred) or open an issue with enough context for reproduction.

## Sponsor / Donate

- Ko-fi is configured in `.github/FUNDING.yml`.
- Popup donation links are configured in `src/shared/donations.ts`.

## Bug Reports

Use the bug report template and include browser version, steps, and expected/actual behavior.

## Security Issues

Do not file public issues for vulnerabilities. See `SECURITY.md` for private disclosure.
